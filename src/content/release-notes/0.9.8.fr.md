## Tishe — première version open source

Tishe est désormais open source : [github.com/PereverzevVV/tishe](https://github.com/PereverzevVV/tishe). Les nouvelles versions y sont publiées, et l’application vous prévient quand une nouvelle version sort.

- **Des sections nommées d’après ce qu’elles font.** « Modèles » s’appelle désormais « Reconnaissance » (de la parole au texte), « IA » s’appelle désormais « Correction IA » (pour corriger le texte). À l’intérieur, rien n’a changé.
- **Un démarrage clair.** Le premier lancement s’affiche au milieu de la fenêtre, « Démarrage rapide » s’ouvre sur « Transcription », et un bouton « Télécharger » apparaît partout où rien ne fonctionne sans modèle.
- **ffmpeg est inclus.** Plus besoin de l’installer séparément pour transcrire des fichiers.
- **Une nouvelle icône** et un nouveau nom de programme : `tishe.exe`. Les paramètres, l’historique et les modèles ont été déplacés d’eux-mêmes dans le nouveau dossier.
- **« La suite »** — une page sur les prochaines versions : enregistrement des réunions, résumés, recherche dans les réunions.
- **« À propos » → « Licences »** — les licences de toutes les bibliothèques et de tous les modèles utilisés par Tishe.

Vous avez trouvé un bug ou il vous manque quelque chose ? Écrivez-nous dans [Issues](https://github.com/PereverzevVV/tishe/issues).
