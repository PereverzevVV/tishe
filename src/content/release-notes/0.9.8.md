## Tishe — first open-source release

Tishe is now open source: [github.com/PereverzevVV/tishe](https://github.com/PereverzevVV/tishe). New versions are published there, and the app tells you when one is out.

- **Sections named by what they do.** Models is now Recognition (speech to text), Neural network is now AI editing (fixing the text). Inside, everything is as before.
- **A clear start.** The first run sits in the middle of the window, Quick start opens on Transcription, and a Download button appears wherever nothing works without a model.
- **ffmpeg is included.** No separate install is needed to transcribe files.
- **A new icon** and a new program name, `tishe.exe`. Settings, history and models moved to the new folder on their own.
- **What's next** — a page about the coming versions: meeting recording, summaries, search across meetings.
- **About → Licenses** — the licenses of all libraries and models Tishe uses.

Found a bug or missing something? Tell us in [Issues](https://github.com/PereverzevVV/tishe/issues).
