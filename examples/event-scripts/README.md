# Скрипты событий Tishe

Tishe может сообщать другим программам, как идёт расшифровка файла. В разделе **«Расшифровка» → «Дополнительно» → «Интеграции» → «Скрипт событий»** выберите программу или скрипт (`.exe`, `.ps1`, `.bat`, `.cmd`). Tishe запускает её при каждом событии и передаёт событие **одной строкой JSON во входной поток (stdin)**. Кнопка «Проверить» отправляет тестовое событие и показывает, удалось ли его доставить.

Готовые примеры:

| Скрипт       | Что делает                                                                                                                          |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| `log.ps1`    | дописывает каждое событие в `%TEMP%\tishe-events.log` (или в файл из переменной `TISHE_EVENT_LOG`); удобен для отладки и как шаблон |
| `toast.ps1`  | уведомление Windows, когда файл готов или упал                                                                                      |
| `coucou.ps1` | прогресс на «острове» [Coucou](https://github.com/Louis-CFM/coucou): строка «часть 2 из 3 · 47% · осталось ~12 мин»                 |

Чтобы сделать сразу несколько вещей, напишите свой скрипт, который вызывает нужные примеры по очереди.

## Формат события

```json
{
  "version": 1,
  "app": "tishe",
  "event": "progress",
  "job_id": "1790701283000-1234",
  "file": "D:\\rec\\lecture.mp4",
  "stage": "transcribing",
  "part": 2,
  "total_parts": 3,
  "fraction": 0.47,
  "elapsed_secs": 840,
  "eta_secs": 720,
  "message": "Распознавание: часть 2 из 3 · 47% · осталось ~12 мин"
}
```

| Поле                                    | Когда есть             | Значение                                                                                  |
| --------------------------------------- | ---------------------- | ----------------------------------------------------------------------------------------- |
| `version`                               | всегда                 | версия формата; меняется только при несовместимых изменениях, новые поля могут появляться |
| `app`                                   | всегда                 | `"tishe"` (до выпуска 2026-10-15 было `"handy-plus"`)                                     |
| `event`                                 | всегда                 | `started`, `progress`, `finished`, `failed`, `cancelled` или `test` (кнопка «Проверить»)  |
| `job_id`                                | всегда                 | одинаковый у всех событий одного файла                                                    |
| `file`                                  | всегда, кроме test     | полный путь к исходному файлу                                                             |
| `elapsed_secs`                          | всегда                 | сколько секунд прошло с начала файла                                                      |
| `message`                               | всегда                 | готовая короткая строка на языке интерфейса; у `failed` — текст ошибки                    |
| `stage`                                 | `progress`             | `extracting`, `splitting`, `transcribing`, `post_processing`, `writing`                   |
| `part`, `total_parts`                   | `progress`             | текущая часть (с 1; 0 — до нарезки) и сколько их всего                                    |
| `fraction`                              | `progress`, `finished` | общий прогресс от 0 до 1                                                                  |
| `eta_secs`                              | `progress`             | оценка оставшегося времени; появляется после 15% и 30 с работы                            |
| `output_path`, `characters`, `warnings` | `finished`             | готовый документ, число символов, нефатальные предупреждения                              |
| `error`                                 | `failed`               | текст ошибки                                                                              |

## Как Tishe запускает скрипт

- `.ps1` — через `powershell -NoProfile -ExecutionPolicy Bypass -File`, остальное — напрямую. Окно консоли не появляется.
- События одного файла приходят строго по порядку, по одному запуску на событие.
- `progress` — не чаще настройки «Как часто сообщать о прогрессе» (по умолчанию раз в 10 с) и сразу при смене этапа или части. Если скрипт не успевает, промежуточные `progress` пропускаются, а `started`/`finished`/`failed`/`cancelled` доставляются всегда.
- Скрипт, который работает дольше 10 с, принудительно завершается. Ошибки скрипта пишутся в журнал Tishe и никак не влияют на расшифровку.
- Событие приходит в UTF-8. Windows PowerShell 5.1 читает stdin в кодировке консоли и портит кириллицу, поэтому в примерах stdin читается как байты: `[Console]::OpenStandardInput()` → `[Text.Encoding]::UTF8.GetString(...)`. Скопируйте этот кусок в свой скрипт. Сами `.ps1` сохраняйте в ASCII или в UTF-8 с BOM.
