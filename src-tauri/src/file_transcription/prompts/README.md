# Инструкции нейросети (промпты)

Эти файлы — встроенные инструкции для редактуры расшифровки. Программа вшивает их при сборке (`include_str!` в `language.rs` и `numbered.rs`).

| Файл | Когда используется |
| ---- | ------------------ |
| `ru.txt` | текст записи на русском |
| `ru_careful_rule.txt` | добавляется к `ru.txt` только для Gemma 4 E4B и E4B QAT (стенд, DOCUMENTATION §9.4) |
| `en.txt` | текст записи на английском |
| `universal.txt` | любой другой язык; `{language}` заменяется названием языка по-английски (German, Spanish…) |
| `line_rule.txt` | добавляется к любой инструкции, встроенной или своей: формат пронумерованных строк |

Свою инструкцию на вкладке «Файл» пользователь вписывает вместо `ru.txt` / `en.txt` / `universal.txt`, а `line_rule.txt` добавляется к ней всегда.

**Менять формулировку — только по замерам**: несколько кусков, 3+ повтора, сравнение с текущей. Два прогона одной инструкции различаются не меньше, чем две разные инструкции (DOCUMENTATION §5.15).
